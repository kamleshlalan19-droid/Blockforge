# ⛏️ KamCraft

A browser-based voxel sandbox game inspired by classic block-building games.

**KamCraft** is a JavaScript/Three.js project that lets you explore a procedurally generated world, break and place blocks, collect resources, craft items, and survive.

## 🎮 Play

**[Play KamCraft](YOUR-GITHUB-PAGES-LINK-HERE)**


## ✨ Features

* 🌎 Procedurally generated voxel world
* ⛏️ Break and place blocks
* 🎒 Inventory and hotbar
* 🛠️ Crafting and tools
* 🌲 Trees, caves, ores, and different terrain
* 🌙 Day/night cycle
* 👾 Creatures and combat
* ❤️ Health and hunger
* 💾 World saving
* 🎮 First-person controls
* ⚡ Optimized for browser performance

## 🕹️ Controls

| Key             | Action             |
| --------------- | ------------------ |
| **W A S D**     | Move               |
| **Mouse**       | Look               |
| **Space**       | Jump               |
| **Shift**       | Sprint             |
| **Ctrl**        | Crouch             |
| **Left Click**  | Break / Attack     |
| **Right Click** | Place / Use        |
| **1–9**         | Select hotbar slot |
| **Mouse Wheel** | Switch hotbar slot |
| **E**           | Inventory          |
| **Esc**         | Pause              |
